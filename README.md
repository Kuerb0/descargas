# descargas

Instaladores de las apps de Kuerb0 que no caben en el [portal](https://kuerb0.github.io/portal/) (GitHub no admite ficheros de más de 100 MB en un repositorio). Cada uno es una *Release*.

| App | Última versión | Descarga |
|---|---|---|
| Viajes | 2.0.0 | [Releases → viajes-v2.0.0](https://github.com/Kuerb0/descargas/releases/tag/viajes-v2.0.0) |
| Finanzas Personales | 2.0.0 | [Releases → finanzas-v2.0.0](https://github.com/Kuerb0/descargas/releases/tag/finanzas-v2.0.0) |
| Administrador de Tareas+ (antes Logeador) | 1.4.0 | [Releases → logeador-v1.4.0](https://github.com/Kuerb0/descargas/releases/tag/logeador-v1.4.0) |
| Estadística | 1.0.0 | [Releases → estadistica-v1.0.0](https://github.com/Kuerb0/descargas/releases/tag/estadistica-v1.0.0) |
| Calendario | 2.3.1 | [Releases → calendario-v2.3.1](https://github.com/Kuerb0/descargas/releases/tag/calendario-v2.3.1) |
| Post-It | 2.0.0 | [Releases → postit-v2.0.0](https://github.com/Kuerb0/descargas/releases/tag/postit-v2.0.0) |

Atlas del conocimiento y Apagador publican sus releases en sus propios repositorios: [Atlas](https://github.com/Kuerb0/Atlas-del-Conocimiento-App/releases/latest), [Apagador](https://github.com/Kuerb0/Apagador-App/releases/latest).

Los instaladores se construyen con [herramientas-apps](https://github.com/Kuerb0/herramientas-apps) (`construir.py exe`) y se instalan en el usuario, sin permisos de administrador.
Windows puede avisar porque no están firmados: «Más información → Ejecutar de todas formas».
