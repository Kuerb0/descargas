# descargas

Instaladores de las apps de Kuerb0 que no caben en el [portal](https://kuerb0.github.io/portal/) (GitHub no admite ficheros de más de 100 MB en un repositorio). Cada uno es una *Release*.

| App | Descarga |
|---|---|
| Viajes | [Releases → viajes-v1.7.0](https://github.com/Kuerb0/descargas/releases/tag/viajes-v1.7.0) |
| Logeador | [Releases → logeador-v1.3.0](https://github.com/Kuerb0/descargas/releases/tag/logeador-v1.3.0) |

Los instaladores se construyen con [herramientas-apps](https://github.com/Kuerb0/herramientas-apps) (`construir.py exe`) y se instalan en el usuario, sin permisos de administrador.
Windows puede avisar porque no están firmados: «Más información → Ejecutar de todas formas».
